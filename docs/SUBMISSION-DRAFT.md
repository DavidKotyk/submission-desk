## Name
Submission Desk

## Tagline
Catch the gaps a checked checklist misses—and keep preparation separate from actual submission.

## What it does
Submission Desk gives independent hackathon builders one local workspace for deadlines, requirements, source links, evidence, submission copy and receipts. Its packet audit exposes missing artifacts, placeholder URLs and unlinked evidence even when all checklist items are checked. Manual repository/video checks remember the exact inspected URL and time; editing that link makes its review stale. JSON backups preserve notes and attachments, while Markdown exports provide a portable handoff. The app never sends an entry or certifies organizer acceptance.

## Build and provenance
Dependency-free JavaScript, HTML, CSS and a small Node.js static server. No paid API or runtime model. The initial prototype was created during the submission period before Skill Pack use. The pack was then read and applied to the documented scope/PRD/spec, verified exact-URL-review increment and shipping preparation. User-delegated autonomous work adapted the pack's usual flipped interviews; this is disclosed in docs/WORKFLOW.md rather than claimed as the unmodified curriculum. Organizer eligibility review remains authoritative.

## Demonstration and evidence
Actual local browser recording shows a completed synthetic checklist still carrying packet gaps, recording an example access review, invalidating it by editing its URL, attaching evidence, exporting and separately recording a synthetic receipt. Gapwise/Raincheck are fictional packets, not other implemented products. See current test/browser/video reports for verification counts.

## Limits and next steps
The audit checks recorded data, not real website permissions, source truth or legal eligibility. Reviews and receipts are self-reported. Browser storage is unencrypted and limited; no cloud backup or multi-tab synchronization. Next steps should start with independent builder feedback and observed usefulness, rather than claiming unmeasured time savings.
