# Limits and evidence boundaries

- No rule extraction, automatic eligibility decision, link fetch, access authentication, actual submission, reminder service or account integration.
- Placeholder checks are hostname heuristics, not proof of public access or comprehensive detection of private addresses.
- Access reviews and receipts are manually entered and can be inaccurate or fabricated. Exact-URL equality detects link edits, not remote content changes, later permission changes or expired reviews. A URL changed back to its previous value matches the previous record again.
- Evidence notes/files are not interpreted or certified. A nonempty note can satisfy local completeness while being irrelevant; the user must inspect it.
- Data lives unencrypted in browser localStorage, with quota limits and last-save-wins behavior across tabs. Export JSON backups; Markdown does not include attachment bytes.
- Development and diagnostic examples are assistant-authored, not independent user validation. No measured time savings, willingness to pay, novelty or prize probability established.
- Original prototype predates required Skill Pack use. Later planning/increment are documented honestly; no retroactive claim of plan-first development or organizer eligibility approval.
