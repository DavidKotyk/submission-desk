# Submission Desk scope

## The Unique Kernel
A checked checklist can hide missing submission artifacts. Show preparation, local evidence gaps, manually checked artifact access, and an organizer receipt as separate facts.

## The Core Loop
Record an event and rules → prepare links/copy → inspect packet gaps → attach evidence → personally check artifact access → export a portable handoff → submit at the organizer's website and record its receipt.

## What Working Looks Like
A user completes a synthetic checklist but sees placeholder links and missing evidence in Packet audit. They replace an artifact link, save an access-check note, then edit the link: its previous review becomes stale. Export preserves the distinction; actual submission stays unrecorded until separately entered.

## The POC Boundary
Single-person local browser workspace; several entries, explicit time zones, manual requirements/evidence, JSON backup and Markdown handoff. No remote accounts, paid services or model inference.

## Inspiration & Identity
The user requested a hackathon-entry organizer and then prioritized a real cash reward. Their first entry exposed the difference between prepared materials and actual submission. Preserve the existing quiet green desk design and readable forms.

## Explicitly Cut
Automatic legal eligibility decisions, scraping official rules, automated submissions, account logins, background reminders, cloud synchronization, AI-generated personal reflections and payments.
